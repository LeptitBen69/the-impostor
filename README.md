# The Impostor

Team building word game in English.

- Host (big screen): open https://leptitben69.github.io/the-impostor/#host
- Players: scan the QR code, type the game code and their name. Seats are given automatically.
- The host controls the rounds; phones only show the word of the current round.
- Live sync between the big screen and phones uses ntfy.sh (free, no account).
